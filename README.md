# Parking-Detection
This parking detection project mainly using the Technology of YOLOv8 to predict parking spot at street location. Since there are limited location around my house with many cars within the households, it will be a good idea to have Real-time stream Protocol from security camera feed to predict parking spot using YOLOV8.
